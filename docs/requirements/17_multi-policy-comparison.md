# REQ-17: 다중 실손 판정 + 비교 (L3)

- 요청일: 2026-07-09
- 상태: 완료
- 스프린트: 33
- PM: [PM-39](../pm/39_sprint33-multi-policy-compare.md)

## 요청 원문
> 2개의 실손 중 하나만 선택 가능한데, 중복 선택하면 여러 개 비교해서 (어느 게 유리한지) 안내해주면 좋겠다.

## 핵심 목표
- 여러 실손을 골라 각각 판정하고, 세대·자기부담 차이와 비례분담을 비교 제시.
  (실손 비례분담 사실 반영 — "더 받는 법" 아닌 "어느 약관 유리 + 안분")

## 기능
| # | 기능 | 상태 |
|:--|:--|:--|
| F-1 | 가입현황 다중선택(체크박스, 세대 태그) | 완료 |
| F-2 | 보험별 각각 판정(임시 slots N회) | 완료 |
| F-3 | 비교표(세대·자기부담·likelihood) + 추천 | 완료 |
| F-4 | 비례분담 proration(안분/설명) | 완료 |
| F-5 | 보험 탭 전환 + 좌측 근거 PDF 연동 | 완료 |

## 비고
- 단일 선택/단건 페르소나는 기존 단일 판정 하위호환.
- 비례 안분 수치는 급여/비급여 금액 분해 시 표시(미분해 시 자기부담률 비교로 graceful).
