# REQ-18: 전 페르소나 대응 고도화 + 가로 약관 반 크롭

- 요청일: 2026-07-09
- 상태: 완료
- 스프린트: 34
- PM: [PM-40](../pm/40_sprint34-persona-serving-and-landscape-crop.md)

## 요청 원문
> 삼성화재나 현대해상같이 약관 원본이 세로가 아닌 가로 형식인 것들은 반으로 잘라서 보여주면 안 되나?
> 추가로, 지금은 질문을 잘 물어봤을 때만 잘 나온다. 이 서비스를 쓰는 사람 중 처음부터 자기 상황을
> 100% 자세히 말하는 사람은 거의 없다. 노인분들은 그냥 단순하게 물어볼 거고, 보험 미가입이거나
> 개인정보 공유를 꺼리는 사람은 진료내역·가입보험을 공유하지 않는다. 이런 시나리오를 정확히 설계해서
> 이들 모두를 충족시키는 서비스로 고도화해야 한다.

## 페르소나
- **P1 정밀형**: 로그인 + 마이데이터 + 상세 진술 → 정밀 판정(기존 happy path 유지)
- **P2 간단형/노인**: 불완전 진술 → 답변-우선 그레이스풀 + 큰 글씨
- **P3 익명형**: 무로그인·무개인정보 → 일반 실손 표준약관 기준 상담

## 핵심 목표
- insurer 를 모르면(익명이든 미공유든) **실손 표준약관 기준**으로 답한다(보험사 필터 없는 교차검색 +
  표준 프레이밍). 한국 실손은 금감원 표준약관 기반이라 5개사 핵심 조항이 거의 동일 — 기존 코퍼스 재사용.
- 대충 물어도 결론을 먼저 주고, 부족 정보는 최대 1회만 부드럽게 되묻는다.

## 기능
| # | 기능 | 상태 |
|:--|:--|:--|
| F-1 | 가로 2단 약관 반 크롭(왼/오른/전체 토글, 하이라이트 위치 자동 단 선택) | 완료 |
| F-2 | 답변-우선 그레이스풀 판정(결론 먼저·헤지 선문구 금지·후속 1회) | 완료 |
| F-3 | 게이팅 완화(insurer/product/incident_date 차단 필수 제외, 되묻기 최대 1회) | 완료 |
| F-4 | 익명 진입(welcome 2차 CTA → identity/coverage 건너뜀) | 완료 |
| F-5 | 표준약관 모드(결정론 standard_mode — 보험사 오지칭 차단, PII 0) | 완료 |
| F-6 | HelpLauncher 전역 마운트(welcome·익명 포함) | 완료 |
| F-7 | FontSizeToggle 전 페이지 헤더 노출(노인 접근성) | 완료 |

## 비고
- 금감원 실손 표준약관 원본 PDF 별도 인덱싱은 데이터 트랙(백로그). 이번엔 5개사 교차검색으로 "표준" 구현.
- 라이트박스 확대는 전체 페이지 유지(프리뷰만 크롭).
- 정밀 흐름(P1)은 insurer 존재 시 기존 게이팅 그대로 — 회귀 0.
