# 데모 계정 (이름 + 휴대폰 번호로 로그인)

본인 확인 화면에서 **이름**과 **휴대폰 번호**를 직접 입력해 로그인한다(드롭다운 선택 제거됨).
아래 10개 중 하나를 입력하면 그 사용자의 가입 보험·진료내역이 연동된다.
실 마이데이터 연동 전 합성(가짜) 데이터다 — 원본: `data/demo/{personas,mydata,health}.json`.

> (`POST /api/v1/auth/demo-login`). 목록에 없는 값을 입력하면 404.
