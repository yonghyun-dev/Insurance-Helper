# 데모 계정 (이름 + 휴대폰 번호로 로그인)

본인 확인 화면에서 **이름**과 **휴대폰 번호**를 직접 입력해 로그인한다(드롭다운 선택 제거됨).
아래 11개 중 하나를 입력하면 그 사용자의 가입 보험·진료내역이 연동된다.
실 마이데이터 연동 전 합성(가짜) 데이터다 — 원본: `data/demo/{personas,mydata,health}.json`.

## 시연 시나리오 3종 (페르소나별)

### ① 정밀형 — 로그인 + 가입보험 (김민서)

1. Welcome → `내 보험으로 정확히 확인하기` → 김민서 / 19850412 / 010-1234-5678 → 동의 2건 → 조회.
2. 가입현황: 실손 2건(삼성 4세대 · 현대 3세대) + 비례분담 배너 → **2건 체크** → `2개 보험 비교하기`.
3. 상황: "지난주 계단에서 넘어져 발목이 부러졌어요. 입원해서 수술받았고 통원도 3번 했어요."
4. 확인 포인트: 비교표(세대·자기부담률) + 추천 + 탭 전환 시 좌측 근거 PDF 전환. 가로 약관은 왼/오른/전체 단 크롭 토글 + 조항 하이라이트.

### ② 익명형 — 로그인 없이 (개인정보 미공유)

1. Welcome → **`로그인 없이 그냥 물어볼게요`** (본인확인·마이데이터 전부 건너뜀).
2. 상황: "발목 다쳐서 병원 다녀왔어요. 실손 되나요?" (일부러 짧게).
3. 확인 포인트: 되묻기 **최대 1회** 후 **결론이 첫 문장**인 판정. "**실손 표준약관 기준으로는** …" 프레이밍 + "내 보험으로 확인하면 더 정확해요" + 사이드바 "비로그인 · 표준약관 기준". 특정 보험사를 '가입하신 보험사'로 지칭하지 않음.

### ③ 무보험 로그인형 — 로그인했지만 가입보험 0건 (신하율)

1. Welcome → `내 보험으로 정확히 확인하기` → 신하율 / 19990214 / 010-1111-2222 → 동의 → 조회.
2. 가입현황: **"연동된 가입 실손이 없어요"** 빈 상태 + "표준약관 기준으로 안내" 안내 → `상황 입력으로 계속`.
3. 상황: "감기몸살로 동네 병원 두 번 갔어요. 실손 청구 되나요?"
4. 확인 포인트: 차단 없이 진행 → 표준약관 기준 판정(교차 인용 + 하이라이트). 로그인 상태는 유지(사이드바 "인증 완료").

> 공통: 상황 제출 후 로딩 화면은 단계 애니메이션 + 순환 힌트로 항상 움직이며,
> 첫 응답 텍스트가 생성되기 시작하면 즉시 챗 화면으로 넘어가 실시간 타이핑으로 표시된다.
