# 접근성 안내 페이지 명세서

- 라우트: `/legal/accessibility`
- 스프린트: 8 (대국민 서비스 진입 기준)
- 우선순위: ★★ (WCAG AA 명시)
- 관련: [design-system.md § 5 접근성](../design-system.md), [ui-spec.md § 8.2 FontSizeToggle](../ui-spec.md)

## 1. 목적

WCAG AA 준수 명시 + 사용자에게 사용 가능한 접근성 기능 안내 (폰트 크기 토글, 키보드 단축키, 스크린리더 지원). 노인·장애인 포함 모든 사용자가 본 서비스를 동등하게 사용할 수 있도록.

## 2. 사용자 시나리오

1. **저시력 사용자** — 폰트 크기 토글 사용법 확인
2. **키보드 only 사용자** — 단축키 / Tab 순서 확인
3. **스크린리더 사용자** — 본 서비스가 자신의 보조 기술과 호환되는지 확인
4. **운영자/접근성 감사자** — WCAG AA 준수 선언 확인

## 6. 상호작용

- `<FontSizeToggleDemo>` — 실제 글자 크기 토글이 본 페이지 안에서도 즉시 동작 (헤더의 토글과 동기화)
- 키보드 단축키 표: 각 행 클릭 가능 (단축키 시뮬레이션 — 옵션, 시각 표시만)
- 메인 링크 / 관련 문서 링크는 풀 포커스 ring + 키보드 navigable

## 7. 접근성 (메타)

본 페이지 자체가 접근성 가이드이므로 가장 엄격한 기준 적용:

- 모든 표 (`<table>`) 에 `<caption>` 명시 + `<th scope>` 명시
- 단축키 표: `<kbd>` 시멘틱
- 인라인 데모 토글: ARIA `role="radiogroup"` (헤더 토글과 동일)
- 페이지 진입 시 `<h1>` 에 focus 이동
- 모션 감소 명시 자체가 `prefers-reduced-motion` 미디어쿼리 검증 케이스
- `<lang="ko">` 명시
