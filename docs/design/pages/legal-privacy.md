# 개인정보 처리방침 페이지 명세서

- 라우트: `/legal/privacy`
- 스프린트: 8 (대국민 서비스 진입 의무)
- 우선순위: ★★★ (의무 + 법무 검토 필수)
- 관련: [design-system.md](../design-system.md), Sprint 8 `app/security/pii.py` (PII 마스킹 정책)

## 1. 목적

개인정보보호법 제30조 ("개인정보 처리방침의 수립 및 공개") 의무 이행. PII 마스킹 정책 (Sprint 8 `app/security/pii.py`) 을 사용자에게 투명하게 공개. 감사 로그 보존 정책 (7년 [확인 필요]) 명시.

## 2. 사용자 시나리오

1. **헤더 푸터 링크 클릭** → 본 페이지로 이동
2. **첫 사용자가 사용 전 검토** — "내 정보가 어떻게 처리되는지" 확인
3. **분쟁/민원 발생 시 — 본인 정보 조회 가능 여부 확인**

## 6. 상호작용

- 절 제목 (`<h2>`) 클릭 시 앵커 링크 (`/legal/privacy#section-2` 등)
- 마스킹 패턴 표: 각 행 hover 시 예시 표시 (`010-1234-5678` → `[PHONE]`)
- 보존 기간 표: 색 구분 (휘발성 vs 영구)

## 7. 접근성

- 표 (`<table>`) 에 `<caption>` 명시
- 마스킹 예시는 `<code>` 시멘틱 (스크린리더가 "PHONE" 으로 읽음)
- 정기적 갱신 (법무 검토 후) 시 `<time datetime="...">` 사용

## 8. 데이터 출처

- 정적 페이지. backend API 호출 없음.
