# 데이터 출처 페이지 명세서

- 라우트: `/legal/sources`
- 스프린트: 9~10 (외부 데이터 등장 시)
- 우선순위: ★★ (투명성)
- 관련: [external-apis.md](../external-apis.md), [design-system.md § 1.3 출처 색상](../design-system.md)

## 1. 목적

본 서비스가 활용하는 데이터의 **출처를 사용자에게 투명하게 공개**. 환각이 아닌 검증된 데이터 기반 답변임을 입증. 정부·협회 공식 데이터 사용으로 신뢰성 확보.

## 2. 사용자 시나리오

1. **신뢰성 검토** — "이 답변이 어디서 온 데이터인가" 확인
2. **분쟁 시** — 인용 출처를 직접 확인할 수 있는 외부 링크 활용
3. **연구자·언론** — 본 서비스의 데이터 출처 인용

### 3.2 모바일

각 출처 카드 세로 쌓기. 좌측 색 라인 유지 (출처 종류 즉시 인지).

## 4. 컴포넌트 분해

| 컴포넌트 | variant |
|:--|:--|
| `<ChatHeader>` | 재사용 |
| `<SourceCard>` | 신규 — 출처 1건 카드 (좌측 색 라인 + 제목 + 메타 + 외부 링크) |
| `<SourceCardList>` | 신규 — SourceCard 5개 묶음 (Sprint 9~10 점진 노출) |
| `<RelatedLinks>` | 재사용 |
| `<BackToMainButton>` | 재사용 |

`<SourceCard>` Props:

```tsx
type Props = {
  kind: 'terms' | 'law' | 'standard' | 'disease' | 'calc';  // 색·아이콘 결정
  title: string;
  operator: string;  // "법제처" / "HIRA" 등
  description: string;
  meta: { label: string; value: string }[];  // 갱신 주기 / API URL / 법적 근거 등
  externalLink?: string;  // 클릭 시 새 탭으로 외부 사이트 이동
};
```

## 5. 콘텐츠

위 와이어프레임의 5개 카드. Sprint 진행에 따라 점진 노출:
- Sprint 9 도입: 약관 + 법령 + 표준 + 진단코드 (4개)
- Sprint 10 도입: 계산 (1개 추가)

## 6. 상호작용

- 외부 링크: 새 탭으로 이동 (`target="_blank" rel="noopener noreferrer"`)
- 카드 hover: 미미한 elevation (`box-shadow` 강화)
- 모바일에서는 카드 자체가 외부 링크 (전체 영역 탭)

## 7. 접근성

- 외부 링크에 `aria-label="새 탭에서 {title} 열기"` + 시각 아이콘 (외부 링크 표시)
- 출처 종류는 색뿐 아니라 카드 좌측 라벨 (`▌약관` 식 시각 텍스트) 로도 표시 — WCAG SC 1.4.1

## 8. 데이터 출처

- 정적 페이지. 단 외부 링크는 실 URL 유지 (분기 갱신 — PM 책임)

## 9. SEO / 메타

- `<title>` "데이터 출처 — 보험청구심사 어시스턴트"
- 검색 인덱싱 허용

## 10. [확인 필요]

1. **로고/이미지** — 정부 기관 로고 사용 가능 여부 (저작권 — 정부 공공 저작물 자유이용 라이선스 적용)
2. **외부 링크 깨질 위험** — 분기 PM 책임으로 점검 (또는 자동 모니터링 — Sprint 11+)
3. **각 보험사 약관 PDF 직접 노출** — 저작권 — 약관규제법 vs 저작권법 검토 (Sprint 10 크롤링 자동화와 함께)
4. **본 페이지에 SourcesCard 가 노출되는 시점** — Sprint 9 부터 (외부 API 통합 시작) — Sprint 8 에서는 약관 카드 1개만 노출
