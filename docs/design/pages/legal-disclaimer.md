# 면책·이용약관 페이지 명세서

- 라우트: `/legal/disclaimer`
- 스프린트: 8 (대국민 서비스 진입 의무)
- 우선순위: ★★★ (의무)
- 관련: [design-system.md](../design-system.md), [ui-spec.md § 8.1 DisclaimerBanner](../ui-spec.md)

## 1. 목적

대국민 서비스 운영에서 법적 책임 한정을 명시. 사용자가 답변을 "보험사 공식 결정" 으로 오인하지 않도록 명확한 면책 표시. 모든 페이지 헤더의 `<DisclaimerBanner>` "자세히 보기" 링크 클릭 시 본 페이지로 이동.

## 2. 사용자 시나리오

1. **헤더 배너 클릭** → 본 페이지로 이동
2. **첫 사용자가 사용 전 검토** — 최초 접속 시 (선택 — 약관 동의 모달이 있다면 거기서 본 페이지 링크)
3. **답변 받은 후 법적 위치 확인** — AssessmentCard 의 Disclaimer 텍스트에서 링크 노출

## 5. 콘텐츠 (Sprint 7 톤 적용)

### 5.1 제목

"면책 및 이용약관"

### 5.2 본문 (5 절 — 잠정안, 법무 검토 필요)

**1. 본 서비스의 성격**

> 본 서비스는 보험 약관·법령·표준 자료를 바탕으로 한 참고용 가이드입니다. 법적 효력이나 보험사의 최종 청구 가능 판단을 대체하지 않습니다.

**2. 책임의 한정**

> 본 서비스 제공자는 본 안내에 의존하여 발생한 결과에 대해 책임을 지지 않습니다. 정확한 청구·지급 여부는 가입하신 보험사의 약관과 심사에 따릅니다. 본 안내가 실제 보험사 결정과 다를 수 있으며, 보험사 결정이 항상 우선합니다.

**3. 사용자 의무**

> 사용자는 본 서비스에 입력하는 정보가 본인이 보유한 정확한 정보임을 보장합니다. 거짓 정보 입력 시 안내 결과는 신뢰할 수 없으며, 그 결과의 책임은 사용자에게 있습니다.

**4. 데이터 출처**

> 본 서비스는 공개된 보험 약관 PDF, 국가법령정보센터, 손해보험협회 표준 자료, 건강보험심사평가원 진단코드 등을 활용합니다. 자세한 출처는 [데이터 출처](/legal/sources) 페이지에서 확인하실 수 있습니다.

**5. 분쟁 처리**

> 본 서비스 이용 중 분쟁이 발생한 경우 [확인 필요 — 운영자 연락처/이메일] 로 문의하실 수 있습니다. 보험 청구 자체의 분쟁은 가입하신 보험사 또는 금융감독원 분쟁조정위원회 (국번없이 1332) 에 문의하시기 바랍니다.

## 6. 상호작용

- 스크롤: 부드러운 스크롤 (`scroll-behavior: smooth`). 절 제목 클릭 시 해당 절로 이동 (앵커 링크)
- "데이터 출처 보기" 링크: 같은 탭에서 `/legal/sources` 로 이동
- "메인으로 돌아가기": `react-router` `navigate(-1)` 또는 `/` 로 명시 이동
- 페이지 진입 시: `window.scrollTo(0, 0)` 자동 (라우트 변경 시 표준)

## 7. 접근성

- 페이지 진입 시 `<h1>` 에 focus 자동 이동 (스크린리더 알림)
- 절 제목 `<h2>` — `id` 부여 (앵커 링크)
- 각 절 본문 행간 1.6 + `--text-base` (16px 기본)
- "메인" 링크 `aria-label="메인 채팅 화면으로 돌아가기"`
- 면책 본문에 `<article>` 시멘틱 + `aria-labelledby="page-title"`
- 폰트 크기 토글 (헤더 `<FontSizeToggle>`) 영향 받음

## 8. 데이터 출처

- 정적 페이지. backend API 호출 없음.
- 콘텐츠는 frontend 코드 (또는 markdown 파일 import) 에 직접 포함

## 9. SEO / 메타

- `<title>` "면책 및 이용약관 — 보험청구심사 어시스턴트"
- `<meta name="description">` "본 서비스의 법적 책임 한정 안내"
- 검색 엔진 인덱싱 허용 (`<meta name="robots" content="index, follow">`)
