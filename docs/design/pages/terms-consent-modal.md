# 약관 동의 모달 명세서

- 라우트: (모달, 페이지 X) — 첫 진입 시 `App.tsx` 최상단 조건부 렌더
- 스프린트: 11 (선택 — 운영자 결정)
- 우선순위: ★ (의무 아님, 단 법무 권장)
- 관련: [legal-disclaimer.md](legal-disclaimer.md), [legal-privacy.md](legal-privacy.md)

## 1. 목적

대국민 서비스 첫 진입 시 사용자가 면책·개인정보 처리방침에 명시적으로 동의했음을 기록 (`localStorage["termsAgreedAt"]`). 분쟁 시 동의 시점 입증 자료.

운영자 결정 사항 — Sprint 11 활성화 여부 확정 후 구현.

## 2. 사용자 시나리오

1. **최초 접속 사용자** — 모달 강제 노출, 동의 후 메인 화면 진입
2. **재방문 사용자** — `localStorage` 기록 있으면 모달 미노출
3. **약관 갱신 시점** — `localStorage` 의 동의 시점 < 약관 갱신 시점이면 재동의 요구

## 5. 콘텐츠

위 와이어프레임의 4 조항 요약. 자세한 내용은 별도 페이지 링크.

## 6. 상호작용

- 진입: 모달 자동 표시. focus trap (`Tab` 이 모달 안에만 순환)
- 스크롤: 끝까지 도달해야 체크박스 활성 (사용자가 실제 읽었음 검증)
- "동의" 버튼: 체크박스 + 스크롤 모두 충족 시 활성. 클릭 시 `localStorage["termsAgreedAt"] = ISO8601` + 모달 닫힘 + 메인 진입
- "동의하지 않음": 빈 페이지 또는 외부 (예: `about:blank` 또는 외부 보험 안내 사이트) 이동
- Esc 키: 동의 안 했으면 동작 안 함 (강제 동의)

## 7. 접근성

- `role="dialog"` + `aria-modal="true"` + `aria-labelledby` (제목)
- focus trap — `react-focus-trap` 라이브러리 권장
- 진입 시 첫 focus 위치: 스크롤 영역 (스크린리더가 본문 읽기 시작)
- 체크박스 활성/비활성: `aria-disabled` + 시각적 disabled

## 8. 데이터

- 백엔드 호출 없음. `localStorage` 만 사용.
- `localStorage["termsAgreedAt"]`: ISO8601 timestamp (예: "2026-05-25T12:34:56Z")
- 약관 갱신 시점 (frontend hardcoded): `TERMS_LAST_UPDATED = "2026-05-25"` — 이 값 변경 시 재동의 요구
